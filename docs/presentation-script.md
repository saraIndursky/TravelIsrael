1. **חור אבטחה:** בהתחלה, מי שיצר מקום יכל להעלות אותו בעצמו לסטטוס "מאושר" דרך קריאה ישירה ל-API. הידקתי את מדיניות ה-RLS כך שבעלים יכול רק לשלוח ל-pending, ואישור הוא למנהל בלבד.

## תשובות לשאלות צפויות

**מה עלות ההפעלה?**
Vercel ו-Supabase בתוכנית החינמית, ו-Gemini במכסה החינמית. ללא עלות כרגע. בקנה מידה גדול העלות תלויה במספר המשתמשים והקריאות ל-AI.

**איך המידע מאובטח?**
הרשאות ברמת הדאטהבייס (RLS), מפתחות סודיים רק בשרת ולא בקוד או ב-GitHub, ואישור מנהל לכל תוכן חדש.

**מה קורה אם ה-AI לא זמין?**
העוזר נופל אוטומטית למצב גיבוי, והטופס ממשיך לעבוד.

**מה הייתי משפרת?**
מיילים מדומיין מאומת, חיפוש טקסט מלא, עימוד בצד השרת, ובדיקות אוטומטיות מלאות ב-CI.

**למה Supabase?**
מסד נתונים, התחברות, אחסון תמונות וזמן אמת במקום אחד, עם הרשאות ברמת השורה.
